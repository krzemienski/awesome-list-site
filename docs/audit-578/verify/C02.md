# C02 — Submitters can no longer forge AI confidence or analysis timestamps

**Status: FIXED — proven on DEV, 2026-10-09 (run `__qa_test_plan_582_1791561997330`)**

## Before
Per the audit: a DEV submission with caller-made `claudeMetadata` returned 201, stored `confidence: 1` and a fresh
`claudeAnalyzedAt` without any model call, and the admin queue showed it as "AI 100%".

## Fix
- `catalog-contributions.ts`: any client-supplied `claudeMetadata` / `claudeAnalyzedAt` returns **400**
  "Client-provided AI analysis is not accepted". New edits always store `claude_metadata = NULL`.
- `PendingEdits.tsx`: stored historical analysis is labelled **"Unverified legacy analysis"** in the row, and
  **"Unverified — not trusted AI output"** in the detail dialog. No confidence percentage or suggested values are shown.
- `suggest-edit-dialog.tsx` no longer sends analysis output (Analyze/Apply only fills the form).
