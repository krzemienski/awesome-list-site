# F02 — Partial seeding shows counts and the failed items

Status: **FIXED + PROVEN** (scratch DB, browser desktop + mobile)

## Before
`DatabaseTab.tsx` always toasted "Database Seeded Successfully" with insertion counts and never rendered `errors`/`totalErrors` (audit OPS-02).

## Fix
`/admin/database` shows a persistent result panel; with errors it is `seed-result-partial` ("Seeding partially failed — N item(s) not imported", WARNING chip)
with counts and every error message. The success toast is only used for error-free runs.

## Steps

1. Desktop: /admin/database → Seed Database → confirm. Panel:
   `Seeding partially failed — 1 item not imported WARNING Categories inserted: 0 Subcategories inserted: 0 Sub-subcategories inserted: 0 Resources inserted: 1 Errors: 1 No deepest category found for "__qa_test_plan_seed_invalid" with categories: __qa_test_plan_missing_category`
   DB: exactly one row, id 197908 `__qa_test_plan_seed_valid`.
2. Mobile retry, same source: `… Resources inserted: 0 Errors: 1 No deepest category found for "__qa_test_plan_seed_invalid" …`; DB still exactly one row (197908) — no duplicate.
