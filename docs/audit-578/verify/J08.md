# J08 — Hosted font fetch validation exists but is not automatic release gate

**Status: PROVEN (2026-10-09)**

## Fix
- `accent-drift.mjs --network` (`npm run validate:webfont-fetch`) requests every hosted stylesheet live. These are the pre-paint `<link>` in `client/index.html` and every `FONT_STYLESHEETS` URL. For each one it records:
  - HTTP status;
  - the requested versus served families (parsed from the `@font-face` blocks);
  - whether the font-file hosts are allowed by CSP `font-src`.
- Exit codes: 1 = the provider rejected a URL or family (a defect); 2 = transport failure or 5xx outage (inconclusive); 0 = pass. `--evidence=<file>` keeps the raw per-URL JSON.
- **Release automation:**
  - New CI job `webfont-fetch` in `.github/workflows/test.yml`. It fails on exit 1, warns on exit 2, and always uploads `webfont-evidence/`.
  - Registered Replit validation command **`webfont-fetch`** (`npm run validate:webfont-fetch`).
- The offline gate's NOTE now points to the registered command; it no longer says "not registered".

## Before
`evidence-589/j08-before.log`: the offline run passes and prints "the live webfont probe did NOT run (offline by default, and not registered as a gate)". A self-consistent invalid family therefore passes.
