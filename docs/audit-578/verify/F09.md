# F09 — A failed link-health job shows its reason

Status: **FIXED + PROVEN** (scratch DB, browser desktop + mobile)

## Before
The dashboard rendered `latestJob.status` but never `latestJob.errorMessage` (audit OPS-06).

## Fix
A `role=alert` banner shows the terminal reason and time, labels the counts as coming from the previous completed scan, and offers "Run scan again".

## Steps / evidence
1. Fixture: link_health_jobs id 3, status failed, error_message 'Interrupted by server restart' (after completed job 2).
2. /admin/linkhealth desktop + mobile: banner text
   `Scan #3 failed at …: Interrupted by server restart  Counts and problem links below are from the previous completed scan (#2 …).  Run scan again`.
3. Run scan again → confirm → `POST /run` 200 job 4 → completed 10/10; banner disappears.
