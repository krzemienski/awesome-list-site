# I02 — Violet primary-button labels fail AA in Editorial, Geist and Swiss

**Status: FIXED and PROVEN** (2026-10-09, DEV :5000, guest)

## Before
Canonical `.btn.primary` paints `#0a0a0a` on Violet `#9d4edd` = **4.3061:1** (13px/600, not large text) in Editorial, Geist and Swiss.

## Fix
`client/src/styles/app-bridge.css`: non-Terminal filled `.btn.primary` (and the shadcn default variant that maps to it) consume `--on-accent` (= `#000000`), giving 4.5675:1 on Violet. `[data-system="terminal"]` is excluded so its outlined grammar (transparent fill, accent-ink label) survives; Brutalist already used `#000` and is unchanged visually. Documented in `canonical-token-parity` deviations and the artifact addendum. Frozen CSS untouched.
