# J14 — Preview dependency tree lacks automatic vulnerability coverage

**Status: PROVEN (2026-10-09) — zero unreviewed moderate+ advisories; 4 reviewed exceptions remain.**

## Fix
- New gate `scripts/validation/artifact-dependency-audit.mjs` (`npm run validate:artifact-deps`):
  - resolves the design-system artifact's 8 declared dependencies and their 130-package transitive closure from the locked `package-lock.json`;
  - runs `npm audit --package-lock-only --json` against the live advisory database;
  - intersects the advisories with that closure;
  - fails any moderate-or-higher advisory that has no reviewed exception.
- Exceptions live in `scripts/validation/artifact-dependency-audit-exceptions.json`. Each one carries a reason and a `reviewed` date, and expires after 120 days.
- If the advisory service gives no usable report, the gate exits 2 (inconclusive); this is not a pass.
- **CI:** new job `design-system-artifact-deps` in `.github/workflows/test.yml`. It runs `npm ci` (the locked tree), then the audit with `--evidence=artifact-audit/advisories.json`, and uploads that JSON.
- Registered Replit validation command **`artifact-deps`**.
- **Patch:** `package-lock.json` updated to the compatible `browserslist` fix, which removes a HIGH advisory (see Before).
- The remaining Vite and esbuild advisories are fixed only in Vite majors that this artifact's toolchain cannot take now (vite 6.4.3+ / 8.x). They are recorded as **reviewed exceptions**, because the artifact runs only as a Linux dev preview and has no production service.
