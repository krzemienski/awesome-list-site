# A01 — Public resource metadata exposes agent, cost, email, IP and internal notes

**Status: FIXED — proven on DEV 2026-10-09 16:07–16:08 UTC (run `__qa_test_plan_580_1791562070462`).**

## Fix
- `server/lib/publicResource.ts` `stripInternalResourceFields` is an allowlist: top-level public columns only, and `metadata` is rebuilt from
  `ogImage, ogImageBlurhash, favicon, siteName, author, scrapedTitle, scrapedDescription, ogTitle, ogDescription, twitterCard` (strings),
  `tags` (string array) and `featured/urlScraped` (booleans). Every other metadata key (agent, cost, email, ip, internalNotes, notes, model,
  researchJobId, nested objects, …) is dropped. Tag-based kind inference (`resolvedKind`) is kept.
- Every resource send site goes through it: detail/list/search/home/related/awesome-list tree+listing, `/api/public/*`, published
  collections, bookmarks, favorites; continue-learning exposes only `resourceId/title/category`.
