# C03 — Ordinary users' edit submissions trigger zero paid AI calls

**Status: FIXED — proven on DEV, 2026-10-09 (run `__qa_test_plan_582_1791561997330`)**

## Before
Per the audit (code-traced): `POST /api/resources/:id/edits` used only `isAuthenticated`. `triggerClaudeAnalysis: true`
called `analyzeURL` synchronously, before duplicate rejection. Omitted or false queued background `analyzeURL`.
Neither path went through admin authorization, `aiLimiter` or the daily quota.

## Fix
- `catalog-contributions.ts`: edit submission never calls the Claude service (no synchronous call and no background
  call). `triggerClaudeAnalysis: true` returns **403** "Edit submission does not run AI analysis. Administrators must use
  /api/claude/analyze." A non-boolean value returns 400. Duplicate rejection (409) happens without any AI.
- Admin analysis stays on `POST /api/claude/analyze` (`isAuthenticated, isAdmin, aiLimiter` + per-admin daily quota,
  `admin-content.ts`). The suggest-edit dialog's Analyze button calls only that route and is rendered only for admins.

## Proof — admin analysis through the shared limiter/quota (1 paid call)
`evidence-582/scripts-browser-analyze.mjs`, output `browser-analyze.json`, ledger `../paid-ai-ledger.md`.
1. Admin `requestCount` before = **0**.
2. In a real browser, the admin opens `/resource/188651` → Suggest Edit → URL `https://github.com/FFmpeg/FFmpeg` →
   **Analyze with AI**. `POST /api/claude/analyze` returns 200 with suggestions at 95% confidence.
3. **Apply AI Suggestions** fills the form: title "FFmpeg: Comprehensive Multimedia Processing Libraries and Tools",
   the description, and category "Media Tools". Screenshot: `evidence-582/C03-admin-analyze-apply.png` (opened).
4. **Submit**. Captured body: `{"proposedData":{"title":…,"description":…,"url":"https://github.com/FFmpeg/FFmpeg","category":"Media Tools"}}`.
   It contains no analysis fields. The server answered **409** field `url` because the URL already belongs to resource
   #185662 "FFmpeg (GitHub mirror)" (C05 check), so no edit was created. The dialog stays open:
   `evidence-582/C03-admin-submit-after-apply.png` (opened).
5. Admin `requestCount` after = **1**, exactly one paid call.
6. Limiter evidence (`quota-probe.json`): an admin request with an invalid URL right afterwards returned 400 with
   `RateLimit-Policy: 10;w=900` and `RateLimit-Remaining: 8`. The paid call and this probe both consumed the shared AI
   limiter (10 per 15 min). The same probe as a non-admin got 403 under the global limiter only (`600;w=60`).
