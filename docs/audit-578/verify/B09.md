# B09 — Repeated recommendation query parameters returned 500

**Status: FIXED and proven** with anonymous curl/fetch against DEV, 2026-10-09. No paid AI was used: every call is anonymous and rule-based, and `refresh=true` was never used.

## Before (audit evidence)
`GET /api/recommendations?categories=a&categories=b` → **500** `{"message":"Internal Server Error"}`. Express parses repeated keys as arrays, and the handler called `.split` on them.

## Fix
`server/routes/domains/journeys-recommendations.ts` validates every profile parameter as a scalar bounded string or enum, using a zod schema mirrored in `server/contracts/endpointSchemas.ts`, before building the anonymous profile.
- Array or object values → `400 "Invalid recommendation profile query"`, or the contract layer's `400 "Invalid query parameters"` for `limit` and bracket objects.
- Comma-separated values keep working.
