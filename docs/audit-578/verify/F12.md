# F12 — GitHub panel updates automatically after Pull / Sync now

Status: **FIXED + PROVEN** (scratch DB, disposable private repo, browser desktop)

## Before
GitHubSyncPanel queries had no refetch interval (global infinite staleTime), so a processing job never turned terminal without a manual refresh (audit OPS-03).

## Fix
`/api/github/sync-status` polls every 3 s only while an item is pending/processing; history is invalidated whenever queue data changes; polling stops on terminal state.
Also found while proving: the import read README.md through unauthenticated raw.githubusercontent.com, so private repositories could never be imported
(first Pull failed "File not found: README.md"). `GitHubClient.fetchFile` now sends the configured token and retries anonymously on a miss.
