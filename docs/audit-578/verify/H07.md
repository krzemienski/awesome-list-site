# H07 — Guest bookmark and missing-detail titles change between crawl and client passes

**Status: FIXED and proven on DEV and on a local production build (2026-10-09).**

## Before
- `/bookmarks`: curl title "Bookmarks — Awesome Video", but the client title was "Saved on This Device".
- Missing resource/journey: curl title "Page Not Found — Awesome Video", but the client titles were "Resource Not Found" / "Journey Not Found", with different descriptions.

## Fix
- GuestBookmarks, the ResourceDetail missing branch and (in this pass) the JourneyDetail missing branch use the shared server templates from `shared/seo-templates.ts` (`missingPageSeo` and the bookmarks template). The visible h1 copy stays specific.
- noindex is kept and there is no canonical.

## Recipe executed
1. **Bookmarks and missing resource.** Script `evidence-587/h07h08.mjs` → `h07h08-out.txt`. For each case it curls the server HTML, then reads the browser head after a reload and after SPA navigation. It ran on DEV `:5000` and on a production build (`NODE_ENV=production node dist/index.js` on `:5055`), at editorial 1440 and brutalist 390:

| Case | HTTP | Server title | reload = SSR | SPA = SSR | visible h1 |
|---|---|---|---|---|---|
| bookmarks (empty) | 200 | Bookmarks — Awesome Video | yes | yes | Nothing saved on this device |
| bookmarks (populated via localStorage) | 200 | Bookmarks — Awesome Video | yes | yes | Saved, for now. |
| `/resource/99999999` | 404 | Page Not Found — Awesome Video | yes | yes | Resource Not Found |

"Equal" means the title, description, single `noindex, nofollow` robots and 0 canonicals all match exactly.

2. **Missing journey.** Script `evidence-587/h07j.mjs` → `h07-journey-out.txt`, run after the JourneyDetail edit:
```
SSR {"status":404,"title":"Page Not Found — Awesome Video","desc":"The page you're looking for doesn't exist on Awesome Video. ...","robots":"noindex, nofollow","canonicals":0}
{"sys":"editorial","w":1440,...,"reloadEq":true,"spaEq":true}   h1 "Journey not found."
{"sys":"brutalist","w":390,...,"reloadEq":true,"spaEq":true}
```
Before the edit, curl and the client disagreed: the client showed title "Journey Not Found" with description "This learning journey may have been removed or archived."
