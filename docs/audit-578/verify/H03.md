# H03 — Filtered taxonomy links serve unfiltered server cards and totals

**Status: FIXED and proven on DEV (2026-10-09).**

## Before (from the audit)
- `/category/encoding-codecs?kind=libraries`: the server HTML showed 333 resources, while the scoped listing API said 9.
- `?subcategory=Codecs`: 333 versus 23.
- `?kind=libraries&page=2`: served unfiltered page 2.

## Fix
- og-middleware's taxonomy section resolves kind, child-scope (`subcategory=`), `filter=general`, `search`, `sort`/`sortBy` and facets with the same scoped-listing resolver as the client's API.
- Filtered requests bypass the path+page HTML cache instead of poisoning it.
- Canonical policy is deliberate and unchanged: filtered views canonicalise to the unfiltered node and stay indexable. `?page=N` keeps its own canonical.
- Out-of-range policy:
  - filtered pages clamp to the last real page (`?kind=libraries&page=2` renders the single filtered page, 9 items);
  - unfiltered pages past the end return 404.

## Recipe executed
Script: `evidence-587/parity.mjs` (taxonomy cases: `evidence-587/tax-cases.json`). Same method as H02: server HTML ids/total/title, compared with the exact listing API, compared with the settled browser DOM. It covers category, subcategory and sub-subcategory levels at editorial 1440 and brutalist 390. Raw results: `evidence-587/tax-editorial-1440.json`, `evidence-587/tax-brutalist-390.json`. Full table: `evidence-587/md-tax.md`.

Excerpt (both combinations are identical):

| URL | SSR total | API total | ids equal (SSR = API = DOM) | canonical |
|---|---|---|---|---|
| `/category/encoding-codecs?kind=libraries` | 9 | 9 | yes (9) | /category/encoding-codecs |
| `/category/encoding-codecs?kind=libraries&page=2` | 9 | 9 | yes (9, clamped) | /category/encoding-codecs |
| `/category/encoding-codecs?subcategory=Codecs` | 23 | 23 | yes (23) | /category/encoding-codecs |
| `/category/encoding-codecs?filter=general` | 92 | 92 | yes (24) | /category/encoding-codecs |
| `/category/encoding-codecs?search=ffmpeg` | 124 | 124 | yes (24) | /category/encoding-codecs |
| `/category/encoding-codecs?sort=name-desc&page=2` | 333 | 333 | yes (24) | …?page=2 |
| `/category/encoding-codecs?tags=open-source&format=tool` | 0 | 0 | yes (0, "0 resources") | /category/encoding-codecs |
| `/subcategory/mobile-web-players?kind=libraries` | 3 | 3 | yes (3) | /subcategory/mobile-web-players |
| `/subcategory/mobile-web-players?sortBy=name-desc` | 67 | 67 | yes (24) | /subcategory/mobile-web-players |
| `/sub-subcategory/quality-testing?search=vmaf` | 4 | 4 | yes (4) | /sub-subcategory/quality-testing |
| `/sub-subcategory/quality-testing?page=2` | 33 | 33 | yes (9) | …?page=2 |

On a direct reload at desktop and 390px, the hydrated client kept the server's initial cards (SSR ids = DOM ids in every row); unrelated cards never replaced them.
