## Before
Audit SEC-08: an admin-created QA resource stored a script-tag string in metadata.tags, served verbatim to anonymous users. Admin PUT accepted an img/onerror tag and `tags:[42]`.

## Fix
Admin create and PUT validate `metadata` with one bounded, strict `editableResourceMetadataSchema`. It uses the shared `tagSchema` (no HTML, no control or bidi chars, length cap), caps the number of tags, and rejects wrong types and unknown keys.
