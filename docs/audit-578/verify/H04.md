# H04 — Encoded taxonomy URLs become self-canonical escaped duplicates

**Status: FIXED and proven on DEV (2026-10-09). Production does not have the redirect yet; it needs a republish.**

## Before (from the audit)
- `%2D` redirected to lowercase `%2d`, not to the plain slug.
- Raw Node GET of `%2d` returned 200 with canonical `/category/encoding%2dcodecs`.
- `curl -L` looped, because curl re-uppercases escapes.

## Fix
og-middleware decodes the taxonomy path segment, matches it against the tree, and issues one 301 to the plain canonical tree path, keeping the query string. Escape hex case is never treated as slug case.

## Recipe executed
1. **curl -L** (`evidence-587/h04.mjs` → `h04-curl.txt`):
```
### http://127.0.0.1:5000
/category/encoding%2Dcodecs -> http://127.0.0.1:5000/category/encoding-codecs code=200 redirects=1
/category/encoding%2dcodecs -> http://127.0.0.1:5000/category/encoding-codecs code=200 redirects=1
/subcategory/community%2Dgroups -> http://127.0.0.1:5000/subcategory/community-groups code=200 redirects=1
/sub-subcategory/web%2dplayers -> http://127.0.0.1:5000/sub-subcategory/web-players code=200 redirects=1
```
2. **Raw Node HTTP, no escape normalisation** (`h04-dev-node.txt`): every variant reaches the plain path in 1 hop, and the canonical equals the plain URL.
3. **Real browser navigation** (`evidence-587/h04b.mjs` → `h04-browser.txt`), editorial 1440 and brutalist 390:
```
{"request":"/category/encoding%2Dcodecs","redirects":[301],"status":200,"url":"/category/encoding-codecs","h1":"Encoding & Codecs","canon":["https://awesome.video/category/encoding-codecs"]}
{"request":"/category/encoding%2dcodecs","redirects":[301],...,"url":"/category/encoding-codecs",...}
{"request":"/subcategory/community%2Dgroups","redirects":[301],...,"url":"/subcategory/community-groups","h1":"Community Groups",...}
{"request":"/sub-subcategory/web%2dplayers","redirects":[301],...,"url":"/sub-subcategory/web-players","h1":"Web Players",...}
{"request":"/sub-subcategory/quality%2Dtesting?page=2","redirects":[301],...,"url":"/sub-subcategory/quality-testing?page=2","canon":["https://awesome.video/sub-subcategory/quality-testing?page=2"]}
```
Every case takes exactly one 301, reaches the plain URL, shows one plain canonical and no loop.

## Deployment comparison (read-only, `h04-prod-node.txt` and the second block of `h04-curl.txt`)
```
https://awesome.video/category/encoding%2Dcodecs -> code=200 redirects=0, canonical https://awesome.video/category/encoding-codecs
```
Production (published 13:29 UTC, before this fix) already emits the plain canonical, so the escaped page is not self-canonical any more. It does not yet redirect. The redirect goes live with the next publish.
