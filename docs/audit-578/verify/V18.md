## 2. /admin/export → Run Link Check (E009)
- **Start:** clicking **Run Link Check** and confirming returned **202** `{started:true, scope:"stored-approved-resource-urls", job:{id:1}}`.
- **While running:**
  - The progress line read "0 of 13 links checked (started …)" (screenshot `V18-export-linkcheck-running-desktop.png`).
  - A second start sent while running returned **409** "A link health check is already running".
- **Result:** the job completed in 24 s with `total 13 / healthy 9 / broken 2 / redirect 0 / timeout 0 / suspect 2`. The DB rows for job 1 were broken 2, healthy 9, suspect 2.
- **Scope check:**
  - There were 13 approved resources and 13 check rows; every approved resource was checked.
  - Every checked URL equals the stored `resources.url`.
  - All 8 fixture URLs appear verbatim in the `/api/admin/export` markdown (200, 2438 bytes). The check scope matches what the export writes.
- **Verdict per fixture:**

| fixture | verdict | http | detail |
|---|---|---|---|
| live 200 | healthy | 200 | |
| 404 | **broken** | 404 | dead: 404 confirmed under browser UA |
| same-host 301 | healthy | 200 | final `/ok/landing` |
| slow 40 s | healthy | 0 | likely bot-block (AbortError under browser UA) |
| 403 | healthy | 403 | likely bot-block/auth wall |
| deep link → `/` | **suspect** | 200 | deep link collapsed to site root |
| → localhost | **suspect** | 200 | redirects off-domain |
| refused port | **broken** | 0 | connection refused (browser-UA verified) |

- **Policy confirmed:**
  - A strict 404 and a refused connection are flagged broken.
  - Timeouts and 403s are **not** called dead; the second pass reclassifies them as bot-blocks (the same rule as in memory `link-scan-false-positives`).
  - **"Redirect" status is not reachable by design.** Redirects are followed: a same-property redirect counts as healthy, and an off-host or root-collapse redirect counts as suspect. The Redirect counter and filter therefore correctly show 0.
- **DEFECT 1 (fixed):** the completion summary read "9 healthy, 2 broken, 0 redirects, 0 timeouts of 13". It left out the suspect count, so the numbers added up to 11, not 13 (screenshot `V18-export-linkcheck-completed-desktop.png`). Fix in `ExportTab.tsx`: add the suspect count to the summary.
