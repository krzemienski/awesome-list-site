# V01 — Signed-in theme preference persistence

**Status: PASS — proven on DEV (real app :5000, real Clerk sessions, real Chromium), 2026-10-10.** No code change was needed: every branch in the recipe behaved correctly.

## How it was run

```bash
node docs/audit-578/verify/task592-harness/v01-theme.mjs desktop   # 1440×900
node docs/audit-578/verify/task592-harness/v01-theme.mjs 390       # 390×844 touch
```

The script mints two throwaway Clerk users through the Clerk backend (`__qa_test_plan_592_v01a_*`, `__qa_test_plan_592_v01b_*`), signs a real browser in with a single-use sign-in ticket, and drives `/settings/theme` by clicking the real `system-option-*` / `accent-option-*` radio cards. Raw step output: `task592-harness/out/V01-desktop.json`, `V01-390.json`.

## Results (identical at 1440 and 390)

| Step | Observed |
|---|---|
| Initial (new account) | `GET /api/user/preferences` theme `null`, page paints editorial/crimson |
| Rapid clicks Terminal → Matrix → Swiss → Violet, no waits | 4 PUTs **serialized** with revisions `null → 1 → 2 → 3`; final server theme `{swiss, violet}`, revision 4; status line "Theme saved to your account." |
| Reload | `data-system=swiss`, `data-accent=violet`; Swiss and Violet radios `aria-checked=true` |
| Fresh browser context (empty localStorage) | before sign-in: editorial/crimson, `ds-system` unset. After ticket sign-in: swiss/violet hydrated from the account, also on the next page |
| Real offline (`context.setOffline(true)`), click Brutalist | page paints brutalist at once; status "Saving theme to your account…"; server still `{swiss, violet}` (the mutation is paused, not lost) |
| Back online | the paused save resumes by itself: server `{brutalist, violet}`, status "Theme saved to your account.", no error toast |
| Cross-tab conflict: tab 2 loaded, tab 1 saves Terminal, then stale tab 2 clicks Geist | tab 2 PUT → **409**; status (role=alert) and destructive toast: "Your account changed elsewhere. This selection is saved only on this device. Retry to save it to your account."; server keeps tab 1's `{terminal, violet}` (no silent overwrite) |
| Click Retry in tab 2 | PUT 200 with the refreshed revision; server `{geist, violet}` |
| Switch tab 1 from user A to user B (B's account pair editorial/emerald) | page paints editorial/emerald from B's account; A's server pair unchanged `{geist, violet}` |
| Page errors | none |

Mode and font override stay device-only (font picker writes only localStorage); there is no light mode, by design.
