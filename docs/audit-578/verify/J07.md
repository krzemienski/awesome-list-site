# J07 — Malformed system selectors can evade skin validator

**Status: PROVEN (2026-10-09)**

## Fix
`scripts/validation/accent-drift.mjs` now parses every app stylesheet selector structurally, instead of accepting only a valid-subset regex. New check `system-skin-malformed` reports:
- unclosed attribute selectors;
- misspelt `data-system` attributes (edit distance), for example `data-sytem`;
- malformed values.

Each report names file and line. Detector canaries cover these cases and run before the gate.

## Environment
- Mutation probes ran in a /tmp copy of the repo built by `/tmp/j589/mkprobe.sh` (tracked plus modified files). The real repo was never edited.
- Browser: DEV :5000.

## Before
`evidence-589/j07-before.log`: the pre-fix gate passed `system-skin`, with no diagnosis for malformed selectors.

## Executed proof — mutation probes (/tmp copy)
A rule was appended to `client/src/styles/pages/home.css` in the copy:
```
[data-sytem="swiss"] .__qa_test_plan_probe {...}
→ FAIL system-skin-malformed :: client/src/styles/pages/home.css line 957: attribute "data-sytem" looks like a misspelt data-system ...   (j07-probe-typo.log)

.__qa_test_plan_probe[data-system="terminal" .btn {...}
→ FAIL system-skin-malformed :: client/src/styles/pages/home.css line 957: unclosed attribute selector (missing "]") ...                (j07-probe-unclosed.log)
```
On the real repo (`accent-repo.log`), every check passes, including `system-skin :: 55 canonical and 7 app [data-system] rule(s) name only offered systems`. The registered validation `accent-drift` → PASSED.
