# I03 — Artifact docs advertised obsolete ink values and incorrect contrast ratios

**Status: FIXED and PROVEN** (2026-10-09; artifact workflow `artifacts/awesome-video-design-system: web` on :20928, app on :5000)

## Before
`artifacts/awesome-video-design-system/docs/04-tokens.md:44` claimed editorial text-3 `rgba(...,.4)`, `07-color.md:17` "38–42%", `17-accessibility.md:20` "40% white ≈ 4.6:1", and `07-color.md` "Violet ~6:1". Real frozen text-3 measures 2.7436–3.5962:1; Violet is 4.57:1 on black and failed raised surfaces. The docs gate only checked fidelity to the frozen handoff copy.

## Fix
- Frozen handoff text kept verbatim beneath an explicit, generated **App-runtime accessibility addendum** (authoritative) at the top of `docs/04-tokens.md`, `docs/07-color.md`, `docs/17-accessibility.md`, built by `scripts/validation/design-system-artifact-docs.mjs` from `tokens.json` + the same compositing calculator as `scripts/validation/app-accent-contrast.mjs` (live text-3 per system, minimum neutral contrast, and all 50 system/accent rows: ink share, upstream minimum, accent-ink minimum, filled-label ratio / "outlined").
- The preview (`src/canonical/CanonicalDocs.tsx`) renders a "Live app-runtime accessibility addendum" card with the 50-row runtime table on the Tokens, Color and Accessibility chapters, sourced from `tokens.json`/`contrast.json`; it states that the historical chapter's 38–42% and ~6:1 claims are not runtime guidance and that actual painted ancestry needs browser measurement (no blanket "all small accent text passes" claim).
