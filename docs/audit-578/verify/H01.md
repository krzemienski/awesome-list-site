# H01 — Explorer tag filters disappear despite 1,047 tagged resources

**Status: FIXED and proven on DEV (2026-10-09).**

## Before
- `/api/awesome-list` returns 1,816 resources: 1,047 have `metadata.tags` and 0 have a top-level `tags` field.
- `client/src/components/ui/category-explorer.tsx` read only `resource.tags`, so it found 0 tags and hid the "Filter by tags" block entirely. It also matched categories and expanded resources against that same empty field.

## Fix
- The Explorer now reads tags through the shared `resourceTags` accessor in `client/src/lib/tags.ts`, which uses the `metadata.tags` authority with normalisation. The same accessor builds the options, the category match counts and the expanded-resource matches.
- 1,535 unique tags exist. The tag list shows the top 20 and has a "Show all 1535 tags" toggle.
- Tag chips are real `<button aria-pressed>` elements, so focus is visible.

## Recipe executed
Script: `evidence-587/h01.mjs` (Playwright, real Chromium, against `http://127.0.0.1:5000/advanced`). Output: `evidence-587/h01-out.txt`.

Truth comes from the live API, computed in the script:
```
truth {"resources":1816,"tagged":1047,"topLevelTags":0,"hls":62,"expect":{"Community & Events":1,"Encoding & Codecs":2,"General Tools":1,"Infrastructure & Delivery":11,"Intro & Learning":3,"Media Tools":4,"Players & Clients":8,"Protocols & Transport":32}}
```
Steps, repeated for editorial 1440, brutalist 1440, editorial 390, brutalist 390 and editorial 375:
1. Open the Explorer tab. The filter block shows 20 tag buttons and the toggle "Show all 1535 tags".
2. Press Tab to reach the `HLS` chip (`button-explorer-tag-hls`). Focus is visible (`outline: solid 3px`, `:focus-visible` true). Press Space.
3. The chip is `aria-pressed="true"`. 8 category cards remain, and their per-card match counts equal the truth exactly (`matchesEqualTruth: true`, `nameOnly: 0`).
4. Press Enter on the first matching card to expand it (`aria-expanded` goes false → true, focus visible). The previewed resource is HLS-tagged (`previewIsHls: true`).
5. Clear the chip. 9 cards return, `aria-pressed="false"`, and no match labels remain.

All 5 viewport/system combinations passed.
