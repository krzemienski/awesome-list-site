# J03 — Integration DB omits migration journal required by admin statistics

**Status: PROVEN — 226/226 on a freshly migrated dedicated test DB (2026-10-09)**

## Fix
`tests/global-setup.ts`:
- Provisions the dedicated test DB with the production journaled migrator (`scripts/migrate.ts`). `drizzle.__drizzle_migrations` therefore holds the real journal; nothing is fabricated.
- It then runs `drizzle-kit push` only to reconcile tables not yet journaled.
- The safety guards are unchanged: the DB name must contain `test`, and a URL equal to DEV is refused.
- The 200 assertion in `admin.test.ts` is kept.

Measuring the real failure set (first full run after the fix, 22:41Z) gave **6 failed / 220 passed**:

| Test | Cause | Resolution |
|---|---|---|
| admin › reject without reason | Missing `reason` produced zod's generic "expected string" message | **App fix:** `admin-content.ts` reject schema gives the "at least 10 characters" message for a missing reason too. The test asserts the `validation_failed` envelope. |
| admin › PUT update resource | Test used a 19-char description; approved resources require ≥20 (the gate replaces a shorter one) | Stale test, given a valid description |
| collections › ownership/sharing | Test bookmarked a `pending` resource, which now correctly answers 404 | Stale test: it bookmarks while approved, unpublishes, then asserts 404 and no leak through the public share |
| resource-kinds › `kind=TOOLS` case-insensitive | **Real regression from the just-merged query contract:** a strict `z.enum` on `kind`/`format`/`provider`/`skillLevel` returned 400 `validation_failed` before the route's case-insensitive matcher ran | **App fix:** `endpointSchemas.ts` documents these as case-insensitive strings, so the route keeps its `invalid_<param>` envelope |
| resource-kinds › unknown kind envelope | Same root cause (`validation_failed` instead of `invalid_kind`) | Same fix |
| resource-kinds › journey step embed keys | Step embeds now go through the shared public serializer, so they carry more public columns | Stale test: asserts the public key set and that internal fields are absent |

Production is not affected by the facet regression. A read-only probe `GET https://awesome.video/api/resources?kind=TOOLS&limit=1` → 200; the strict enum never shipped.
