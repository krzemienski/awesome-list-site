# H08 — Missing resource pages bypass dead-link telemetry

**Status: FIXED and proven for resources, taxonomy and unknown routes (2026-10-09). The journey page part belongs to the journeys task (out of scope here).**

## Before
`reportDeadLink` was called only from the shared NotFound page. ResourceDetail's custom missing branch never reported.

## Fix
- `client/src/lib/route-monitor.ts` adds `useMissingRouteTelemetry(active)`. It reports once per path and re-arms only when the path changes, so rerenders never duplicate a report.
- NotFound and the ResourceDetail genuine-404 branch use it. 5xx and network states never call it.
- In ordinary DEV, reporting stays console-only by design.

## Recipe executed
Production build, because DEV is console-only: `NODE_ENV=production node dist/index.js` on `:5055` with `DISABLE_BACKGROUND_JOBS=1`. Script: `evidence-587/h07h08.mjs` → the `h08` section of `h07h08-out.txt`. It records every request to `/api/telemetry/dead-link` and waits for the page to settle, including rerenders.

| Path | Fault | h1 | telemetry POSTs | body path | status |
|---|---|---|---|---|---|
| `/resource/99999999` | none (real 404) | Resource Not Found | **1** | `/resource/99999999` | 204 |
| `/category/nope-xyz-587` | none | Page Not Found | **1** | `/category/nope-xyz-587` | 204 |
| `/no-such-route-587` | none | Page Not Found | **1** | `/no-such-route-587` | 204 |
| `/resource/184739` | detail 503 (browser route) | Resource temporarily unavailable | **0** | — | — |
| `/resource/184739` | none (healthy) | MPEG Standards Documentation | 0 | — | — |

Every report is rooted and same-origin (`{"path":"/resource/99999999","referrer":null,"ts":…}`).

The missing journey (`/journey/:id`) is not wired to telemetry here, because the task assigns journey page telemetry to the journeys task.
