# Claude Agent SDK (TypeScript)

> LLM-friendly index of the official Claude Agent SDK documentation at code.claude.com. This app's AI research pipeline (server/ai/runAgentQuery.ts, researchService.ts) is built on @anthropic-ai/claude-agent-sdk with an in-process MCP server; these are the authoritative docs for its message semantics, tool bridge, and options. Full site index: https://code.claude.com/docs/llms.txt

Key behavioral fact for this codebase (from the TypeScript reference, SDKAssistantMessage): one API turn can produce SEVERAL assistant messages that share a `message.id`, one per content block, each repeating the same `usage`. Any per-message counting (circuit breakers, token accounting) must dedupe by `message.id`.

## Tools and MCP

- [Give Claude custom tools](https://code.claude.com/docs/en/agent-sdk/custom-tools.md): In-process MCP server (createSdkMcpServer/tool) — the bridge pattern this app uses for check_duplicate, save_discovery, etc.
- [Connect to external tools with MCP](https://code.claude.com/docs/en/agent-sdk/mcp.md): MCP transports, tool search for large tool sets, authentication, and error handling.
- [Configure permissions](https://code.claude.com/docs/en/agent-sdk/permissions.md): Permission modes, hooks, and allow/deny rules (note: bypassPermissions does not restrict tools — use disallowedTools).
- [Intercept and control agent behavior with hooks](https://code.claude.com/docs/en/agent-sdk/hooks.md): Hook execution points for intercepting tool calls and messages.
- [Subagents in the SDK](https://code.claude.com/docs/en/agent-sdk/subagents.md): Define subagents for parallel, context-isolated tasks (this app's orchestrator/scout pattern).
