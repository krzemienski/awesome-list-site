SSR fix verification (read-only build probes)
==============================================

Source change
-------------
Only client/src/App.tsx changed. SSR now uses the explicit
VITE_CLERK_PUBLISHABLE_KEY at module evaluation; browser loads continue to
resolve from window.location.hostname through Clerk's publishableKeyFromHost.
An absent key now throws a clear configuration error rather than Clerk's empty-
host exception. No entry-server.tsx or server SSR change was needed because the
explicit key is resolved before renderHome() and no request-dependent global is
introduced.

Production-shaped disposable build
-----------------------------------
Command used a fake non-secret value (pk_live_not-a-secret) and emitted only to
/tmp/redesign-resume/rendering/fixed-live-key-build (not dist/):
  VITE_CLERK_PUBLISHABLE_KEY=pk_live_not-a-secret npx vite build --ssr \
    src/entry-server.tsx --outDir /tmp/redesign-resume/rendering/fixed-live-key-build
Result: 241 modules transformed; build completed. Import result:
  renderer import ok renderHome export present
